# GETS Bridge - releases

Installers for **GETS Bridge**, the small Windows app that adds strategies from
[QuintalMind](https://www.quintalmind.com) to a Greeksoft GETS terminal (new rules are always added stopped).

- Download the newest version from **[Releases](../../releases/latest)**, or from QuintalMind > Profile > Greeksoft GETS.
- Installed bridges update themselves from here (outside market hours, or via *Check for updates* in the tray menu).
- Every release has a `latest.json` with the installer's SHA-256; the bridge refuses a file that doesn't match.

This repository holds release files only.
